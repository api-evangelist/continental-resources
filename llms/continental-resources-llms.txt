# Continental Resources

It publishes no developer program, no API documentation, and no machine-readable contract of any kind. This file is generated by API Evangelist from the company's own public web surface so that the absence is stated plainly rather than left for each agent to rediscover.

## What this company is

Continental Resources develops unconventional oil and natural gas resources. Its U.S. asset base spans the Bakken of North Dakota, South Dakota and Montana, the Anadarko Basin of Oklahoma, the Powder River Basin of Wyoming, and the Permian Basin of Texas. Internationally it holds a position in Argentina's Vaca Muerta shale and a joint venture in the Diyarbakir Basin of Turkey. The company was taken private in November 2022 in a $4.3B transaction with the Hamm family and is no longer publicly traded.

- No developer portal, API reference, getting-started guide, SDK, CLI, sandbox, changelog or status page exists anywhere on the public site. The complete public site is 56 pages, enumerated from the company's own sitemap, and not one is a developer page.
- No OpenAPI, Swagger, GraphQL, AsyncAPI, gRPC/Protobuf or WSDL contract is published at any probed location on clr.com, www.clr.com or connect.clr.com.
- No `/.well-known/` document is served: security.txt, openid-configuration, oauth-authorization-server, api-catalog, ai-plugin.json, agent-card.json and agent.json all return 404 on the public hosts.
- No MCP server, no A2A agent card, no llms.txt of the company's own.
- No public GitHub organization. The `github.com/continental` org belongs to Continental AG, the German automotive supplier — a different company with a similar name.
- The site runs WordPress, so a `wp-json` REST root exists at https://www.clr.com/wp-json, but it is deliberately closed: it answers 401 with `{"code":"rest_cannot_access","message":"DRA: Only authenticated users can access the REST API."}`. A CMS endpoint the company has switched off is not a published API.

## Software surfaces the company uses, and who actually operates them

Continental Resources is an API consumer, not an API producer. Every transactional surface it points customers, partners and staff at is run by a third-party vendor, so an agent looking for a Continental Resources API is being pointed at somebody else's product:

- [Owner Relations Login](https://app.energylink.com/Public/Signup.aspx): royalty and working-interest owner statements. Operated by EnergyLink (Enverus), not by Continental.
- [Open Invoice](https://www.openinvoice.com/docp/public/OILogin.xhtml): vendor and supplier invoicing. Operated by OpenInvoice (Enverus), not by Continental.
- [Ethics hotline](https://clr.ethicspoint.com/): anonymous Code of Business Conduct reporting. Operated by NAVEX EthicsPoint. This is a conduct hotline, not a security vulnerability disclosure channel — Continental publishes no VDP.
- [Employee Portal](https://connect.clr.com/): a Citrix StoreFront remote-access gateway on a Continental-owned host. Employee-only; returns 403 to anonymous clients.
- Microsoft 365 at portal.office.com, for employees.
